# 04-开发执行步骤

> 每阶段完成后验证通过才进入下一阶段。

## 阶段 0：项目初始化 + 文档体系

**目标**：项目骨架可编译，文档体系完备

- [ ] 创建目录结构
- [ ] 编写 7 份 docs/ 标准文档
- [ ] 创建项目级 CLAUDE.md
- [ ] 安装 Flutter SDK
- [ ] `flutter create` 初始化项目
- [ ] 配置 `pubspec.yaml` 依赖
- [ ] 验证：`flutter doctor` 无报错，`flutter run -d windows` 可启动

## 阶段 1：OCR 引擎

**目标**：双端都能识别游戏截图中的中文

### 1a — Windows OCR
- [ ] 编写 `scripts/ocr_server.py`
- [ ] 安装 PaddleOCR，测试中文识别率
- [ ] 暴露简单 HTTP API（POST 图片 → 返回文字）
- [ ] 验证：对游戏截图识别正确率 > 90%

### 1b — Android OCR
- [ ] 集成 `google_mlkit_text_recognition`
- [ ] 配置中文语言包
- [ ] 验证：对游戏截图识别正确率 > 90%

### 1c — 统一接口
- [ ] 实现 `ocr_service.dart`，封装平台差异
- [ ] 错误处理与超时机制
- [ ] 验证：两端调用同一接口，返回一致的数据格式
