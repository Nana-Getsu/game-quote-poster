# 01-项目需求文档

## 项目名

**游戏截图名句提取工具**（Game Quote Poster）

## 一句话说清楚

玩游戏时截图的精彩对白 → 提取出来 → 生成好看的海报图 → 保存收藏。

## 用在哪

| 平台 | 怎么用 |
|---|---|
| **Windows 电脑** | 打开软件 → 拖入截图 → 自动识别文字 → 排版 → 保存图片 |
| **Android 手机** | 装 APK → 拍照或从相册选图 → 自动识别 → 排版 → 存到相册 |

## 输入

- 拖入或选择图片（JPG / PNG / WebP / BMP 都行）
- 文字可能在**底部**（传统游戏对话框）或**侧边**（视觉小说）
- 自动检测文字区域 + 可以手动微调框选范围

## 文字识别

- 自动提取图片里的中文文字
- 识别结果可以**手动修改**（识别错了能改）
- 纯本地识别，不联网

## 海报生成（两种模式）

### 模式 A：文字叠加（主要模式）

> 把提取的句子**直接放在原图上**，随意拖到任何位置，生成一张完整的图。

- 原图做整张背景
- 文字浮在图上，**可以手指/鼠标随意拖动**到任意位置
- 文字**放大显示**，做装饰点缀效果
- 文字样式可调：字体、颜色、大小、阴影、描边
- 背景可加模糊/滤镜效果

### 模式 B：左图右文

> 左边放原图，右边放文字，适合做壁纸

- 16:9 / 9:16 / 4:3 三种比例
- 文字放左边、右边、上面、下面都可以
- 4 套模板：水墨 / 高斯模糊 / 毛玻璃 / 纯色极简

## 保存

| 平台 | 存到哪 |
|---|---|
| **Windows** | `E:\08 vscodeproject\共享空间\游戏名句海报\` 存图，`名人名言.md` 存文字 |
| **Android** | 手机相册 |

## 设计原则

- **轻量化**：安装包尽量小，不装没用的东西
- **离线运行**：不依赖网络
- **简单直接**：打开 → 拖图 → 排版 → 保存，就四步

## 验收标准

- [ ] 拖入游戏截图，能自动识别出对话框里的中文
- [ ] 识别结果可以手动修改，改完海报上同步更新
- [ ] 文字可以拖到图的任意位置
- [ ] 可以切换字体、颜色、大小
- [ ] 可以切换 4 套模板 / 3 种比例
- [ ] 点保存后，共享空间里出现海报图片和名言记录
