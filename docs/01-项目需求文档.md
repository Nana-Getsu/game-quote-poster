# 01-项目需求文档

## 项目名称

**游戏截图名句提取工具**（Game Quote Poster）

## 一句话概述

从游戏截图中提取中文对话，生成可自由排版的名言海报。

## 用户场景

1. 玩游戏时截图保存精彩对白
2. 打开本工具，拖入截图
3. 自动识别文字区域，提取对话文字
4. 选择喜欢的海报模板和排版
5. 一键生成海报，保存到 Obsidian 或手机相册

## 功能需求

### F1 — 图片输入
- 支持格式：JPG、PNG、WebP、BMP
- 支持方式：拖拽加载、文件选择器、拍照（Android）

### F2 — 文字识别
- 中文 OCR 自动识别
- 自动检测文字区域位置（底部/侧边）
- 支持手动框选微调文字区域
- 识别结果可编辑修正

### F3 — 海报生成
- 3 种输出比例：16:9 / 9:16 / 4:3
- 文字位置可调：左/右/上/下
- 字体可切换（系统字体 + 内置备选）
- 字号可调

### F4 — 设计模板
| 模板 | 说明 |
|---|---|
| 水墨 | 黑白极简，毛笔字风格 |
| 高斯模糊 | 原图做模糊背景，文字叠加 |
| 毛玻璃 | 文字区域半透明模糊 |
| 纯色极简 | 白底/黑底干净排版 |

### F5 — 保存
- Windows：海报图 → `10 Reading/posters/`，名言 → `10 Reading/名人名言.md`
- Android：保存到相册，文字可复制/分享

## 非功能需求

- **轻量化**：安装包不宜过大，桌面端 < 200MB
- **离线运行**：OCR 全本地，不依赖云端 API
- **稳定性**：不崩溃，识别失败时有提示而非闪退

## 验收标准

- [ ] 拖入一张游戏截图，能正确识别中文对话
- [ ] 切换 4 套模板，海报预览实时更新
- [ ] 切换 3 种比例，排版自动适配
- [ ] 手动修正文字后，海报同步更新
- [ ] Windows 端保存后，Obsidian 中能看到海报和名言
- [ ] Android 端保存后，相册中能看到海报
