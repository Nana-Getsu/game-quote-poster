# 07-测试用例

## 功能测试

### TC-01：加载图片
| 项 | 内容 |
|---|---|
| 操作 | 拖入一张 JPG 游戏截图 |
| 预期 | 原图预览区显示完整图片 |
| 边界 | PNG/WebP/BMP 格式均正常显示 |

### TC-02：OCR 识别
| 项 | 内容 |
|---|---|
| 操作 | 加载图片后自动触发 OCR |
| 预期 | 文字编辑框中显示识别结果 |
| 边界 | 无文字图片 → 提示"未检测到文字" |

### TC-03：手动修正文字
| 项 | 内容 |
|---|---|
| 操作 | 在文字编辑框中修改 OCR 结果 |
| 预期 | 海报预览中的文字同步更新 |

### TC-04：切换模板
| 项 | 内容 |
|---|---|
| 操作 | 依次切换水墨/高斯模糊/毛玻璃/纯色 |
| 预期 | 海报预览实时切换，样式正确 |
| 边界 | 快速连续切换不卡顿、不崩溃 |

### TC-05：切换比例
| 项 | 内容 |
|---|---|
| 操作 | 依次切换 16:9 / 9:16 / 4:3 |
| 预期 | 海报预览尺寸切换正确，排版自适应 |

### TC-06：切换文字位置
| 项 | 内容 |
|---|---|
| 操作 | 依次切换左/右/上/下 |
| 预期 | 文字区域位置正确移动 |

### TC-07：切换字体
| 项 | 内容 |
|---|---|
| 操作 | 在下拉列表选择不同字体 |
| 预期 | 海报中的文字字体实时切换 |
| 边界 | 系统无中文字体时，内置字体可用 |

### TC-08：调整字号
| 项 | 内容 |
|---|---|
| 操作 | 拖动字号滑块 (16pt ~ 60pt) |
| 预期 | 海报文字大小实时变化 |
| 边界 | 文字过长时自动缩小字号（不超过 16pt 下限） |

### TC-09：调整裁剪区域
| 项 | 内容 |
|---|---|
| 操作 | 拖拽原图上的裁剪框 |
| 预期 | 重新 OCR 识别新区域文字 |

### TC-10：保存（Windows）
| 项 | 内容 |
|---|---|
| 操作 | 点击保存按钮 |
| 预期 | `10 Reading/posters/` 下生成 PNG，`名人名言.md` 追加条目 |
| 边界 | 目录不存在时自动创建 |

### TC-11：保存（Android）
| 项 | 内容 |
|---|---|
| 操作 | 点击保存按钮 |
| 预期 | 相册中出现海报图片 |
| 边界 | 存储权限未授予时提示并引导授权 |

## 异常测试

| 编号 | 场景 | 预期行为 |
|---|---|---|
| ET-01 | 加载非图片文件 | 提示"不支持的文件格式" |
| ET-02 | OCR 识别为空 | 提示"未检测到文字，请手动调整裁剪区域" |
| ET-03 | ocr_server.py 未启动 | 提示"OCR 服务未运行，请检查 Python 环境" |
| ET-04 | Obsidian vault 路径不存在 | 提示配置 vault 路径 |
| ET-05 | 超大图片（> 8000px） | 自动缩放处理，不 OOM |

## 性能测试

| 编号 | 场景 | 目标 |
|---|---|---|
| PT-01 | OCR 识别耗时 | < 2s |
| PT-02 | 模板切换响应 | < 200ms |
| PT-03 | 海报合成耗时 | < 500ms |
| PT-04 | 应用启动 | < 3s（不含 OCR 模型加载） |
