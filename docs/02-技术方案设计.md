# 02-技术方案设计

## 总体架构

```
┌─────────────────────────────────────┐
│            Flutter UI Layer         │
│  ┌───────────┐  ┌────────────────┐  │
│  │ 原图预览   │  │  海报预览      │  │
│  │ (框选裁剪) │  │  (实时渲染)    │  │
│  └───────────┘  └────────────────┘  │
│  ┌────────────────────────────────┐  │
│  │     控制面板 (模板/字体/比例)   │  │
│  └────────────────────────────────┘  │
├─────────────────────────────────────┤
│          Service Layer              │
│  ┌─────────┐ ┌──────────┐ ┌──────┐  │
│  │OCR服务   │ │图像处理   │ │存储  │  │
│  │(平台切换)│ │(裁剪合成) │ │服务  │  │
│  └─────────┘ └──────────┘ └──────┘  │
├─────────────────────────────────────┤
│          Platform Layer             │
│  ┌─────────────┐ ┌──────────────┐   │
│  │ Win: PaddleOCR│ │Android: MLKit│  │
│  │ (ocr_server.py)│ │(google_mlkit)│  │
│  └─────────────┘ └──────────────┘   │
└─────────────────────────────────────┘
```

## 技术栈

| 层 | 选型 | 版本要求 |
|---|---|---|
| 框架 | Flutter | >=3.10 |
| 语言 | Dart | >=3.0 |
| OCR (Win) | PaddleOCR | >=2.7 |
| OCR (Android) | google_mlkit_text_recognition | >=0.11 |
| 图像处理 | Dart `image` 包 | >=4.0 |
| 状态管理 | Provider 或 Riverpod | 轻量为主 |
| 文件操作 | dart:io (Win) / share_plus (Android) | — |

## 组件树

```
MaterialApp
 └── HomeScreen
      ├── Row

      │   └── PosterPreview (海报实时渲染)
      └── Column

           ├── StylePanel

           │   └── TextPositionSelector (左/右/上/下)

                ├── PickImageButton

                └── SaveButton
```

## 数据流

```
UserAction → [StateNotifier] → UI Rebuild
     ↓
Service Layer (ocr / image / storage)
     ↓
Platform Channel (Win: Python subprocess / Android: ML Kit)
```

- `PosterConfig` 模型持有所有海报参数
- 任意参数变更 → 重新渲染海报预览（防抖 300ms）

## 关键约束

1. **单例 OCR 引擎**：避免重复初始化 PaddleOCR（初始化耗时长）
2. **大图缩放**：预览时缩放到显示尺寸，合成时用原图
3. **内存管理**：处理完释放原图内存，避免 OOM
4. **错误处理**：OCR 失败不崩溃，显示错误提示
