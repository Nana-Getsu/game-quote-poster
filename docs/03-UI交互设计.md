# 03-UI交互设计

```
┌────────────────────────────────────────────────────┐
│  游戏截图名句提取工具                               │
├─────────────────────┬──────────────────────────────┤
│                     │                              │
│   原图预览区        │    海报预览区                │
│   - 显示完整截图    │    - 左侧/上方: 截图部分     │
│   - 半透明遮罩:     │    - 右侧/下方: 文字区域     │
│     非文字区域      │    - 实时跟随参数变化        │
│   - 可拖拽调节:     │                              │
```

## 交互流程

```
  打开图片
     ↓
  ┌─ 拖拽文件到窗口
  │  或
  └─ 点击 [📂 打开图片] → 系统文件选择器
     ↓
  显示原图（左侧预览区）
     ↓
  自动OCR识别文字区域
     ↓
  显示识别结果（可编辑文本框）
     ↓
  ┌────────────────────────────┐
  │ 用户可调整:                │
  │ - 拖拽裁剪框微调           │
  │ - 修改识别文字             │
  │ - 切换比例/模板/字体/位置  │
  │ - 右栏海报实时预览         │
  └────────────────────────────┘
     ↓
  点击 [💾 保存]
     ↓
  Windows: 写入Obsidian vault
  Android: 保存到相册
```

## 设计原则

- **即时反馈**：每个参数调整都实时反映在海报预览中
- **容错友好**：OCR 失败时显示提示，不阻塞后续操作
- **最小操作**：打开图片 → 自动OCR → 一键保存，默认参数即用
- **配色克制**：界面以中性灰为主，不干扰海报色彩判断

## 响应式策略

- Windows 窗口最小尺寸：1280×720
- Android：竖屏为主，上方图片预览 + 下方滚动控制面板
