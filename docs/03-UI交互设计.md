# 03-UI交互设计

## 整体风格

**亮色简洁 + 控件居中**。白底为主，大面积预览区，控件集中在底部。

## 主页面布局

```
┌──────────────────────────────────────────┐
│  游戏截图名句提取             [叠加｜分栏] │  ← 顶栏：标题 + 模式切换
├──────────────────────────────────────────┤
│                                          │
│         原图 / 海报预览区                 │  ← 中间：图占最大面积
│                                          │
│     【模式A：图上直接拖文字】              │
│      ┌──────────────────┐                │
│      │    原图背景       │                │
│      │                  │                │
│      │   ┌─────────┐   │                │
│      │   │ 名句文字  │   │  ← 可拖动     │
│      │   └─────────┘   │                │
│      │                  │                │
│      └──────────────────┘                │
│                                          │
│     【模式B：左图右文，可切换比例】        │
│      ┌──────────┬─────────┐              │
│      │   原图    │ 名句文字 │              │
│      └──────────┴─────────┘              │
│                                          │
├──────────────────────────────────────────┤
│  识别文字: ┌──────────────────────────┐  │  ← 下半：控制面板
│           │ "真正的勇气不是无所畏惧..." │  │
│           └──────────────────────────┘  │
│  模板: [水墨] [高斯模糊] [毛玻璃] [纯色] │
│  字体: [微软雅黑 ▾]  字号: [──●──]      │
│  颜色: [■]  阴影: [──●──]               │
│  [📂打开] [🔄重新识别] [💾保存]          │
└──────────────────────────────────────────┘
```

## 模式 A：文字叠加

| 操作 | 效果 |
|---|---|
| 单指按住文字拖动 | 文字跟着走，放到任意位置 |
| 双指捏合 / 滚轮 | 缩放文字大小 |
| 双指旋转（可选） | 旋转文字角度 |
| 点击文字 | 选中，显示编辑框 |

文字区域有**半透明毛玻璃背景**，让文字始终可读。

## 模式 B：左图右文

| 操作 | 效果 |
|---|---|
| 切换比例 | 16:9 横板 / 9:16 竖版 / 4:3 方版 |
| 文字位置 | 左 / 右 / 上 / 下 |
| 切换模板 | 水墨/模糊/毛玻璃/纯色 4选1 |

## 交互流程

```
打开图片（拖入 / 选择）
      ↓
自动 OCR 识别文字区域
      ↓
文字出现在编辑框里（可手动修改）
      ↓
选模式 A 或 B
      ↓
调样式（字体、颜色、大小、位置）
      ↓
预览实时更新
      ↓
点保存 → 存到共享空间
```

## 错误处理

| 情况 | 提示 |
|---|---|
| OCR 识别失败 | 红色提示条："识别失败，请检查图片是否包含清晰中文" |
| 未加载图片就点保存 | 提示："请先加载图片" |
| Python 环境未配置 | 提示："OCR 服务未启动，请检查 Python 和 PaddleOCR 安装" |
