# 06-海报模板规范

## 通用参数

| 参数 | 说明 |
|---|---|
| 输出分辨率 | 1920×1080 (16:9) / 1080×1920 (9:16) / 1600×1200 (4:3) |
| 格式 | PNG（无损压缩） |
| 图片区域占比 | 约 55%（图文比例 ≈ 5.5:4.5） |
| 文字区域内边距 | 5%（相对于文字区域） |

## 模板 1：水墨 (Ink)

```
┌────────────────┬─────────────┐
│                │             │
│                │  人生如逆旅 │
│   原图         │             │
│   (去色处理)   │  我亦是行人 │
│                │             │
│                │  ——苏轼     │
└────────────────┴─────────────┘
```

| 属性 | 值 |
|---|---|
| 背景色 | 白色 #FFFFFF |
| 文字色 | 黑色 #1A1A1A |
| 字体 | 优先毛笔字体（如系统中装），备选思源宋体 |
| 字号 | 36pt（主文字） / 18pt（出处标注） |
| 原图处理 | 去色 80%（保留一点色彩倾向） |
| 装饰 | 文字下方淡墨渲染底纹 |
| 对齐 | 文字右对齐 |

| 属性 | 值 |
|---|---|
| 背景 | 原图全幅高斯模糊，模糊半径 30px |

| 文字色 | 白色 #FFFFFF |
| 字体 | 思源黑体 Bold |
| 字号 | 32pt |
| 对齐 | 文字居中 |

## 模板 3：毛玻璃 (Glass)

```
┌────────────────┬─────────────┐
│                │ ░░░░░░░░░░░ │
│                │ ░ 人生如逆 ░ │
│   原图         │ ░ 旅我亦是 ░ │
│   (正常显示)   │ ░ 行人     ░ │
│                │ ░░░░░░░░░░░ │
│                │             │
└────────────────┴─────────────┘
```

| 属性 | 值 |
|---|---|
| 左侧 | 原图正常显示 |
| 右侧背景 | 从原图右侧取主色调，半透明 + 模糊 |
| 文字区域 | 毛玻璃卡片（背景模糊 15px + 白色半透明） |
| 文字色 | 根据背景色自动选择黑/白（保证对比度） |
| 字体 | 系统默认中文字体 |
| 字号 | 30pt |
| 对齐 | 文字居中 |

## 模板 4：纯色极简 (Solid)

```
┌────────────────┬─────────────┐
│                │             │
│                │   人生      │
│   原图         │   如逆旅    │
│                │             │
│                │   我亦是    │
│                │   行人      │
└────────────────┴─────────────┘
```

| 属性 | 值 |
|---|---|
| 子模板 | 白底 + 黑字 / 黑底 + 白字 |
| 背景色 | 纯白 #FFFFFF 或 纯黑 #111111 |
| 文字色 | 与背景相反 |
| 字体 | 系统默认中文字体 |
| 字号 | 34pt |
| 装饰 | 无任何装饰 |
| 对齐 | 文字居中 |

## 字体优先级

1. 系统扫描到的中文字体
2. 内置开源字体：
   - 思源黑体 (Noto Sans SC)
   - 思源宋体 (Noto Serif SC)
   - 站酷快乐体（水墨模板专用）
3. 系统默认 sans-serif 兜底
